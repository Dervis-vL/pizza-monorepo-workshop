# data/ 📦

`pizzerias.json` is a sample of the pizza platform API's `GET /pizzerias/all`
response, in its exact wire format. It is what the map shows when
`PIZZA_SOURCE=fixture` (the default), so the app works with no network at all.

Positions and coordinates are approximate. Refresh it from the live API with:

```bash
PIZZA_API_BASE_URL=http://pizzaapie9e130d0-pizza-api.functions.fnc.fr-par.scw.cloud/
```
